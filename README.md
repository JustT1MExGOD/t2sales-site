# T2 Sales Landing Site

Динамичный лендинг для t2sales.ru.

## Файлы
- `index.html` — основная страница
- `styles.css` — стили + анимации
- `script.js` — частицы, счётчики, reveal, форма

## Как задеплоить
1. Залей папку на любой статический хостинг (Netlify, Vercel, Cloudflare Pages, обычный nginx и т.д.).
2. Настрой домен t2sales.ru на этот хостинг.
3. Форма отправляет mailto на vincere-mortem@inbox.ru (можно заменить на свой бэкенд / Telegram Bot API).

## Что можно доработать
- Реальные скриншоты приложения
- Ссылку на Windows-установщик
- Логотип SVG
- Интеграцию формы с бэкендом
- Meta-теги и OG-картинку

Сделано под стиль T2: тёмный фон, розовый + cyan акценты, плавные анимации.
